# LFN Applied Observability for AIOps (A-O/AI) Working Group

A Linux Foundation Networking (LFN) working group building a best practice guide for end-to-end observability and AI-driven operations across telco network stacks. The guide gets validated through a simulated proof of concept by Q4 2026.

## Participants

People from AT&T, Verizon, Turkcell, AWS, Red Hat, and LFN.

- Fatih E. Nar (Red Hat), WG Vice Chair / Technical Lead. Sets technical direction, leads cloud-native observability and the PoC, and is principal author of the best practice guide.
- Tony Hansen (AT&T), Security & Observability TAC Lead
- Murat Parlakisik (AWS), AI/ML Architecture Lead
- Ranny Haiby, LFN CTO

## North-star KPIs

- Sub-200ms closed-loop demo
- TM Forum Autonomous Network (AN) Level 3
- Demonstrated ROI on at least one use case
