# LFN Applied Observability for AIOps (A-O/AI) Working Group

A Linux Foundation Networking (LFN) working group producing a **Best Practice Guide for end-to-end observability and AI-driven operations** across telco network stacks, validated through a simulated Proof of Concept by Q4 2026.

## Participants

Cross-organizational effort involving AT&T, Verizon, Turkcell, AWS, Red Hat, and LFN.

- **Fatih E. Nar** (Red Hat) — WG Vice Chair / Technical Lead: overall technical direction, cloud-native observability, PoC lead, and best practice guide principal author
- **Tony Hansen** (AT&T) — Security & Observability TAC Lead
- **Murat Parlakisik** (AWS) — AI/ML Architecture Lead
- **Ranny Haiby** — LFN CTO

## North-Star KPIs

- Sub-200ms closed-loop demo
- TM Forum Autonomous Network (AN) Level 3
- Demonstrated ROI on at least one use case
